# Copilot × Outlook 可用性打卡

每日记录 Copilot 在 Outlook App 和网页版的可用情况，支持选择使用环境（国内 / 美国 / 墨西哥 / 欧洲）。

## 功能

- **云端同步**：数据存 Cloudflare D1（SQLite），登录后多设备自动同步
- **用户系统**：注册 / 登录 / 退出（服务端 SHA-256 加盐哈希 + 30 天会话令牌）
- **离线兜底**：本地缓存 + 登录时按时间戳合并（同一天新者胜），断网记录自动补传
- **白天 / 黑夜模式**：一键切换，偏好持久化（默认 Raycast 暗色）
- 连续显示两个月日历，点击任意日期打卡
- 绿色 = 两个都可用，橙色 = 部分可用，红色 = 都不可用
- 底部统计：可用天数、按环境分布、最近记录
- 版本号显示于页脚

## 技术说明

前端：纯静态单文件应用（index.html），无构建依赖，部署在 Cloudflare Pages。

后端：Cloudflare Worker（`api/worker.js`）+ D1 数据库，路由挂载在同域名 `copilot.slashbro.top/api/*`（Pages 静态站 + Worker API 同源，无 CORS 问题）。认证为服务端实现：SHA-256 加盐哈希 + 32 字节随机会话令牌（30 天有效期）。

设计风格：Raycast 暗色（Inter + ss03、白色药丸 CTA、#07080a 表面阶梯）。

部署：Cloudflare Pages（GitHub 自动构建）· https://copilot.slashbro.top
