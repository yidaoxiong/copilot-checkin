# Copilot × Outlook 可用性打卡

每日记录 Copilot 在 Outlook App 和网页版的可用情况，支持选择使用环境（国内 / 美国 / 墨西哥 / 欧洲）。

## 功能

- **用户系统**：注册 / 登录 / 退出（SHA-256 加盐哈希，数据按用户隔离，存在本地浏览器）
- **白天 / 黑夜模式**：一键切换，偏好持久化（默认 Raycast 暗色）
- 连续显示两个月日历，点击任意日期打卡
- 绿色 = 两个都可用，橙色 = 部分可用，红色 = 都不可用
- 底部统计：可用天数、按环境分布、最近记录
- 版本号显示于页脚

## 版本历史

- v1.1.0 — 白天/黑夜模式切换；用户注册登录系统；版本号显示；v1.0 匿名数据自动迁移至首个注册账号
- v1.0.0 — 首版：双月日历打卡、环境选择、统计面板

## 技术说明

纯静态单文件应用（index.html），无构建依赖。认证为客户端实现（Web Crypto SHA-256 + localStorage），适合个人工具场景，不是服务端级安全。

设计风格：Raycast 暗色（Inter + ss03、白色药丸 CTA、#07080a 表面阶梯）。

部署：Cloudflare Pages（GitHub 自动构建）· https://copilot.slashbro.top
