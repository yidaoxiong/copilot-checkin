# Copilot × Outlook 可用性打卡

每日记录 Copilot 在 Outlook App 和网页版的可用情况，支持选择使用环境（国内 / 美国 / 墨西哥 / 欧洲）。

- 连续显示两个月日历，点击任意日期打卡
- 绿色 = 两个都可用，橙色 = 部分可用，红色 = 都不可用
- 底部统计：可用天数、按环境分布、最近记录
- 数据存储在浏览器 localStorage，纯静态站，无构建依赖

设计风格：Raycast 暗色（Inter + ss03、白色药丸 CTA、#07080a 表面阶梯）。

部署：Cloudflare Pages · https://copilot.slashbro.top
